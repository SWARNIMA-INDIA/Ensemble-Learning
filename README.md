## 📌 Project Overview

This repository contains complete implementation and explanations of **Ensemble Learning techniques** in Machine Learning.

It includes both:

* ✅ **Theory Questions (Q1–20)**
* ✅ **Practical Implementation (Q21–45)**

The goal of this project is to understand how combining multiple models improves performance, reduces overfitting, and increases stability.

### 🔹 1. Ensemble Learning Basics (Q1–10)

* What is Ensemble Learning
* Types: Bagging, Boosting, Stacking
* Bias vs Variance
* Overfitting and Underfitting
* Weak vs Strong Learners

---

### 🔹 2. Bagging (Q11–20)

* Bagging Concept
* Bootstrap Sampling
* Out-of-Bag (OOB) Score
* Advantages & Limitations

* Feature Importance
* OOB Score

* Performance comparison

## 💡 Key Learnings

* Ensemble methods improve model performance by combining multiple learners
* Bagging reduces **variance**
* Random Forest adds **feature randomness** for better generalization
* Stacking leverages strengths of multiple models
* Evaluation metrics are essential for comparing models
